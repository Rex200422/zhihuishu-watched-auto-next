# 智慧树自动续播脚本

版本：1.9.3  
适用页面：`https://fusioncourseh5.zhihuishu.com/*`

## 功能

- 自动播放当前视频，视频自然结束后等待指定秒数再继续播放。
- 默认从播放器的默认位置或断点开始，向后按顺序查找下一未完成视频。
- 勾选“全部从头播放”后，包含已完成的视频，每个视频都从 0 秒开始播放。
- 可自动进入后续小节，跳过没有学习资源的目录分组标题。
- 支持 1.0、1.25、1.5 倍速，以及 3～30 秒的切换等待时间。（实际支持在脚本里修改L94-L98）
- 可静音当前课程页面；面板支持拖动、折叠，并保存设置与位置。

## 使用方法

1. 在浏览器中安装 Tampermonkey（篡改猴）或 ScriptCat（脚本猫）。
2. 将 `zhihuishu-watched-auto-next.user.js` 导入脚本管理器并启用；也可新建脚本，粘贴文件全部内容后保存。
3. 进入智慧树课程页面，打开需要开始的视频。
4. 在脚本面板中勾选“自动播放并在视频结束后继续”，开始播放当前视频并自动续播。
5. 按需调整下面的选项。

| 选项                           | 作用                                                         |
| ------------------------------ | ------------------------------------------------------------ |
| 当前页无下一视频时尝试下一章节 | 当前小节没有符合条件的后续视频时，进入后面的符合条件的小节。默认模式跳过已完成小节，“全部从头播放”模式包含已完成小节。 |
| 全部从头播放（含已完成视频）   | 勾选时自动开启续播，立即从当前视频的开头播放；之后按顺序播放，包含已完成视频。不勾选时保留默认播放位置，后续只选择未完成视频。 |
| 静音当前课程页面               | 静音本页面的音视频，切换视频后继续生效；取消勾选恢复播放器原先的静音状态。不影响其他标签页或整个浏览器。 |
| 播放倍速                       | 选择 1.0、1.25 或 1.5 倍速。                                 |
| 等待                           | 设置视频结束后切换前的等待时间，范围为 0～30 秒。            |

按住面板标题栏可拖动；点击右上角按钮可折叠或展开。倒计时期间可点击“取消本次跳转”，取消本次切换。关闭自动续播后，脚本停止后续自动操作；已播放的视频不会因此自动暂停。

## 使用提示

- 浏览器若阻止自动播放，请手动点击一次播放器的播放按钮。
- 脚本不会代答测验或处理课程提示；遇到提示、测验或无法识别的目录时，请手动处理。
- 页面结构变化可能影响视频或目录识别，请以实际页面显示和播放状态为准。
- 如有问题可提交issue并附上使用截图和具体问题描述
